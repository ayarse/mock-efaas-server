      Reject client IDs that aren't registered, like real eFaas. When off, unregistered clients skip all checks.

      Reset

      The signing key is kept, so existing tokens stay valid.

      Register clients from scripts

      curl -X POST __BASE_URL__/mock/clients \ -H "Content-Type: application/json" \ -d '{"client_id":"my-app","client_secret":"my-secret", "client_type":"server_side", "redirect_uris":["http://localhost:3000/callback"], "post_logout_redirect_uris":["http://localhost:3000"], "backchannel_logout_uri":null,"frontchannel_logout_uri":null, "allowed_scopes":["openid","efaas.profile","efaas.email"], "allowed_grant_types":["authorization_code","refresh_token"], "allow_offline_access":true}'

      Or load clients from a file on every start: CLIENTS_FILE=./my-clients.json

      Environment variables

      All optional. The ones that change a setting lock it in the UI.

      Variable Default Description
      PORT 36445 Server port
      HOST localhost Server host
      BASE_URL http://HOST:PORT Issuer URL in tokens (set this behind Docker or a proxy)
      STATE_DIR .nefaas Where settings, clients, users and the signing key are saved
      MOCK_PASSWORD (none) Overrides the login password setting and locks it
      STRICT_CLIENTS (none) Overrides strict client mode and locks it
      USERS_FILE (none) Replaces the users on every start
      CLIENTS_FILE (none) Adds or replaces clients on every start
